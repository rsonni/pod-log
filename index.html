    one game per line

    Only you see this — the panel stays hidden unless the page is opened with ?edit on the end of the address. The only thing this page fetches is commander detail from Scryfall, and only for commanders it has no data for yet. Refresh card data does that lookup on demand; Save updated copy then writes a fresh file with the results and your current log baked in, after which it never needs to look anything up again.

    Format is date | deck(seat) vs deck(seat) … | winner | how it ended | what happened. The last field is optional and unlocks the turn counts and kill stats — write it plainly, like Ryan kills Rudy turn 7, Ricardo kills table turn 12, Ryan concedes turn 12 or entire table died turn 8. A bracketed label on the fourth field, like (combat damage), sets how the win is categorized. Add a line, press update, and every number on this page moves. Pods of any size work; a fifth name makes it a five-player table on its own.

    Commander names link to Scryfall, which also supplies the card images on hover. A dotted underline with a dot beside it means the shorthand matched more than one card and the link falls back to a search — pin the exact name in CARD_OVERRIDES to fix it.
